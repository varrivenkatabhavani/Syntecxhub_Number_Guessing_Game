Number Guessing Game
A Number Guessing Game is a Python command-line application where the computer randomly selects a number and the user tries to guess it correctly using higher/lower hints.
Features
Random number generation
Higher/Lower hints
Attempt counter
Difficulty levels
Replay option
Input validation
Technologies Used
Python
Random Module
Command Line Interface (CLI)
How to Run
1. Install Python
2. Save the file as numberguessinggame.py
3. Open terminal or command prompt
4. Run the program:
python numberguessinggame.py
Learning Outcomes
Loops and conditional statements
Random module usage
User input handling
Basic game logic implementation
